# ADR-002: official SDK, stdio, explicit compatibility evidence

Accepted 2026-11-09. Use official `github.com/modelcontextprotocol/go-sdk v1.8.0`.
No custom JSON-RPC implementation, model API, credential reader or sampling.
SDK supports both older initialized sessions and the 2026-07-28 protocol.
Bound input frames; reserve stdout exclusively for JSON-RPC, structured logs on stderr.
The first slice exposes read-only search/status. Memory mutation and context
composition arrive with their storage/provenance/budget acceptance tests.

Sources checked:
- https://modelcontextprotocol.io/specification/2026-07-28
- https://modelcontextprotocol.io/specification/2025-11-25/basic/transports
- https://github.com/modelcontextprotocol/go-sdk/releases/tag/v1.8.0
- https://code.claude.com/docs/en/mcp
- https://code.claude.com/docs/en/skills
- https://learn.chatgpt.com/docs/extend/mcp?surface=cli
- https://learn.chatgpt.com/docs/agent-configuration/agents-md

Official client configuration supports local commands. That establishes the
integration design, not successful subscription operation on a user's account.
Protocol tests and actual authenticated client smoke tests are distinct gates.
Never infer actual model usage from MCP response bytes.

The offline cache lacked SDK-required `segmentio/asm v1.1.3` and `x/time v0.15.0`;
their available newer versions v1.2.1/v0.16.0 are explicitly pinned transitively.
Build and our tests pass with them. Full `go mod tidy` also resolves dependency
test modules (`x/tools v0.42.0`, `jwt/v5 v5.3.1`) absent from this cache; repeat
tidy with network access before release, without downgrading those dependencies.
